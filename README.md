# Quietroot

A quiet garden for busy minds. Free, no ads, no accounts.

Focus sessions, breathing, daily planning, quick check-ins and calming mini-games. Everything you do grows a plant, and nothing is ever taken away. Designed with adults with ADHD and autistic adults in mind: no timers you didn't choose, no scores, sensory settings up front.

**Play:** https://tyrone5519-source.github.io/quietroot/

## Privacy

Everything is saved on your own device. Nothing is sent anywhere.

## Running locally

It's plain HTML, CSS and JavaScript with no build step. Serve the folder with any static server, for example:

```
npx http-server .
```
